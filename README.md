# Tokyo Ghoul RPG — Forge 1.20.1

Новый проект мода Tokyo Ghoul для Minecraft Java Edition 1.20.1 (Forge 47.2.0, Java 17).

## Статус

Это начальный каркас проекта, а не готовый игровой мод. Следующие этапы:
1. Проверить сборку Forge/GeckoLib в GitHub Actions.
2. Нормализовать предоставленные модели, текстуры и анимации и привести их к формату GeckoLib 4.
3. Реализовать сетевые обработчики способностей и синхронизацию состояния.
4. Добавить дерево навыков, прогрессию, интерфейс, задания и остальные фракции.
5. Проверить итоговый JAR в Minecraft.

## Сборка

Откройте вкладку Actions, запустите Build TokyoGhoulRPG или отправьте коммит в main. Готовый JAR будет приложен к успешному запуску как artifact TokyoGhoulRPG-JAR.

## Управление (план)

- G — показать/убрать кагуне
- V — укус
- H — рывок
- L (удерживать) — блок
- K — шквал атак
- J — ярость/ультимейт
- Shift + ПКМ — притянуться к цели
- Shift + ЛКМ — притянуть цель
- B — дерево навыков
- N — задания

Важно: эти клавиши перечислены как согласованная спецификация; они не считаются реализованными, пока соответствующие системы не добавлены и не проверены.
